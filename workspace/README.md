# Workspace

Área temporária para rascunhos, anotações e materiais descartáveis.

## Regras

- Nada aqui é oficial.
- Não commitar segredo, PII ou dado real.
- O que virar decisão deve ir para `docs/` ou `specs/`.
- Limpar periodicamente.

> Conteúdo desta pasta é ignorado pelo Git, exceto este README e `.gitkeep`.
