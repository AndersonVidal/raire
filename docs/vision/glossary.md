# Glossário — RAIRE

**Status:** referência  
**Versão:** 1.0

| Termo | Definição |
| --- | --- |
| **Anúncio/posição paga** | destaque comprado; proibido no MVP |
| **Área de atendimento** | região declarada pelo profissional; cidade/bairro + raio |
| **Avaliação bilateral** | cliente avalia profissional e profissional avalia cliente |
| **Categoria** | classificação curada de serviço |
| **Conexão** | vínculo consentido entre cliente e profissional após aceite |
| **Conexão de qualidade** | conexão útil, com desfecho positivo e sem denúncia procedente |
| **Contato mascarado** | e-mail/telefone parcialmente oculto até consentimento |
| **Coorte observável** | agrupamento permitido para análise (novo, poucas avaliações, região, categoria) |
| **Descoberta** | processo de encontrar profissionais ou oportunidades |
| **Desfecho** | informação declarada sobre o resultado da conexão |
| **Elegibilidade** | condições mínimas para participar de busca, interesse ou avaliação |
| **Exploração** | reserva de slots para candidatos fora do topo baseline |
| **Fairness** | redução de invisibilidade extrema e concentração sem perder relevância |
| **Gini de impressões** | medida de concentração de exposição |
| **Interesse** | manifestação de profissional em um pedido |
| **Mural de necessidade** | área onde clientes publicam pedidos |
| **Novo profissional** | ≤ 30 dias ou ≤ 5 conexões, conforme política |
| **PII** | informação pessoal identificável |
| **Política de ranking** | configuração versionada de pesos, caps e regras |
| **Portfólio** | trabalhos apresentados pelo profissional; não é verificação |
| **Profissional** | autônomo que oferece serviço |
| **Ranking** | ordenação de resultados por relevância e fairness |
| **Reputação contextual** | reputação por categoria, papel e recência |
| **Selo de verificação** | indicação do que foi realmente confirmado |
| **Serviço presencial** | executado no local do cliente |
| **Serviço remoto** | executado à distância |
| **Sinal de confiança** | verificação, histórico, avaliação, resposta, conclusão |
| **Trust & safety** | práticas de proteção contra abuso, fraude e dano |
| **Visibilidade** | exposição de um perfil em resultados |
| **Waiver** | exceção registrada e aprovada por humano |
